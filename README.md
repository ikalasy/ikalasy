### 🔴 &nbsp;Red Whistle

**Personal safety, told straight.**

Safer-route navigation weighted by open city crime data. A one-tap SOS that opens your dialer with 911 ready and reads your address back in large type. Siren, strobe, trusted contacts, and an evidence vault encrypted with a key that never leaves the phone.

Native Android — Capacitor shell with every safety-critical path in Kotlin, because a wrapped website can't run a foreground service and an SOS that dies at screen-lock is a lie. 47 Cloudflare Workers behind it.

`Kotlin` `Capacitor` `Cloudflare` `D1` `Stripe`

**Red Whistle, Inc.** — Delaware C-corp
🟡 In closed testing on Google Play

### 🛡️ &nbsp;ScanForge

**Serious security for small business.**

Enter a domain, get a passive read-only assessment scored 0–100 — where every finding says what's wrong, why it matters, and the exact free fix. TLS, headers, SPF/DKIM/DMARC, DNS hygiene, exposed surface.

The scanner runs on Node's own `tls`/`net`/`dns`. No third-party scan API, so nothing in the path can start charging, start failing, or be talked into doing something active.

`TypeScript` `Next.js` `Prisma` `Postgres` `Stripe`

**Passive only, by construction** — no exploitation code path exists

⚫ Retired — built, shipped, ran in production, now closed

</div>

**Now** — CompTIA A+ certified, with Network+ and Security+ next through WGU
coursework. Finishing my B.S. at WGU while running Red Whistle end to end: architecture, code,

architecture gets decided, not the one auditing it eighteen months later.
